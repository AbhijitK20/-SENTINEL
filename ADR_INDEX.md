# Architecture Decision Index

Planned decisions:

- ADR-001: Start with GRU/LSTM before temporal GNN.
- ADR-002: Use feature vectors as the first model state representation.
- ADR-003: Use scenario-safe rather than random row-level splitting.
- ADR-004: Keep runtime offline and avoid cloud inference dependencies.
- ADR-005: Keep automated response out of the prototype.
- ADR-006: Treat evidence attribution as explanatory association, not causation.

Decision records will be added when implementation choices are made and verified.

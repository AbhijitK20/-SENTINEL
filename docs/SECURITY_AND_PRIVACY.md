# Security And Privacy

## Principles

- Process telemetry locally by default.
- Never commit real credentials, private captures, or secrets.
- Anonymize identifiers in demo data where practical.
- Log metadata and errors without exposing sensitive payloads.
- Treat model artifacts and reports as potentially sensitive.

## Prototype Safety

The prototype provides recommendations and forecasts only. It does not automatically block, isolate, or modify network traffic.

## Data Handling

Dataset licenses, access restrictions, checksums, and transformations must be recorded. Sample data included in the repository must be synthetic or explicitly redistributable.

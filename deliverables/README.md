## The PDF was removed on 2026-09-29

A committed `Trajectory_SIH26153_Idea_Deck.pdf` was generated from the *previous*
seven-slide deck and still contained 25 unfilled `[ADD …]` placeholders,
including the headline metric. It could not be regenerated here because
LibreOffice is not installed.

A stale PDF that contradicts the source of truth is worse than no PDF, so it was
deleted rather than shipped. To produce one:

```bash
uv run python scripts/build_deck.py
soffice --headless --convert-to pdf \
    --outdir deliverables deliverables/Trajectory_SIH26153_Idea_Deck.pptx
```

The `.pptx` is the source of truth. `tests/test_submission_artifacts.py` checks
the `.pptx` for placeholders and stale figures; it cannot check a PDF that is not
in the repository.

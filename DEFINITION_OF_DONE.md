# Definition Of Done

## General

- Acceptance criteria pass.
- Tests or documented manual verification exist.
- Errors are handled clearly.
- Relevant documentation is updated.
- No unsupported capability is presented as available.
- Reproducible command or procedure is recorded.

## Data And ML

- Dataset/version and feature version are recorded.
- Split strategy prevents leakage.
- Random seed and configuration are recorded.
- Baseline comparison is available where relevant.
- Model artifact and metrics are saved.
- Limitations and coverage gaps are documented.

## UI And Demo

- Observed and predicted states are distinct.
- Every forecast includes evidence or an uncertainty message.
- Offline execution is tested.
- Deterministic replay is repeatable.

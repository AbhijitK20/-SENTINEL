# Sprint Plan

## Sprint 0: Discovery And Foundation

Confirm requirements, datasets, contracts, architecture, and tooling. Exit with approved planning package.

## Sprint 1: Ingestion And Features

Implement CSV and PCAP ingestion, validation, normalization, and required feature extraction.

## Sprint 2: States And Labels

Build timestamped windows, state vectors, attack labels, transition targets, and leakage-safe splits.

## Sprint 3: Baseline

Train logistic regression, establish metrics, and create the evaluation harness.

## Sprint 4: Temporal Model

Train the first sequence model and validate next-state and attack forecasting outputs.

## Sprint 5: Rollout And Stages

Implement K-step simulation, probability timeline, lead-time metrics, and stage prediction.

## Sprint 6: Explainability

Add evidence ranking, attribution, MITRE-oriented mapping, and entity context.

## Sprint 7: Demo Application

Build offline interface, deterministic replay, forecast-versus-reality view, and report export.

## Sprint 8: Submission Hardening

Run final benchmarks, audit claims, complete README, architecture document, five-slide outline, and two-minute script.

## Sprint Rule

Each sprint must end with a demonstrable increment or a documented blocker and decision.

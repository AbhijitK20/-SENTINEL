# Demo Plan

## Objective

Show that the system forecasts the next attack stage before it becomes fully observable, while explaining the evidence.

## Two-Minute Sequence

1. 0:00-0:15: State the gap between static detection and forecasting.
2. 0:15-0:35: Start the offline replay and show normal baseline.
3. 0:35-0:55: Show reconnaissance and changing network state.
4. 0:55-1:15: Show rising forecast probability and likely next stage.
5. 1:15-1:35: Open evidence and affected entities.
6. 1:35-1:50: Show actual next stage and forecast lead time.
7. 1:50-2:00: Show baseline comparison and offline/reproducible claim.

## Demo Rules

- Use deterministic data.
- Never hide a failed prediction.
- Clearly label prediction versus observation.
- Avoid claiming production readiness.
